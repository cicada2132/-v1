# 요추 압박률 측정기 (Claude API)

요추 측면 X-ray에서 추체 압박률을 손광현(2010) 논문의 네 가지 방법으로 측정하는 파이썬 프로그램입니다.
Claude API의 코드 실행 도구로 추체 모서리와 전방·후방 높이를 재고, 새 대화로 여러 번 독립 측정한 높이를 평균해 압박률을 계산합니다.

> 의료기기가 아닙니다. Claude가 내는 좌표는 근사치이므로, 결과 폴더의 측정점 이미지로 점 위치를 확인한 뒤 사용하세요.

## 측정 방법

| 방법 | 계산식 | 기준 높이 |
|---|---|---|
| 방법 1 | 1 − AVH/PVH | 같은 추체의 후방 높이 |
| 방법 2 | [(V1+V3)/2 − V2] ÷ [(V1+V3)/2] | 위·아래 인접 추체 전방 높이의 평균 |
| 방법 3 | 1 − V2/V1 | 위 인접 추체 전방 높이 |
| 방법 4 | 1 − V2/V3 | 아래 인접 추체 전방 높이 |

- AVH·PVH: 골절 추체의 전방·후방 높이
- V1·V2·V3: 위 인접 추체·골절 추체·아래 인접 추체의 전방 높이
- 기준으로 쓰는 인접 추체도 측정 대상 골절 추체이면 결과에 `※기준 추체 골절`로 표시합니다.

## 동작 방식

1. 사진을 Claude가 실제로 보는 크기로 미리 줄여 업로드합니다. 눈으로 보는 좌표와 코드로 재는 좌표를 같은 픽셀 기준으로 맞추기 위해서이며, 비율 계산에는 영향이 없습니다.
2. `measure_prompt.txt`를 시스템 프롬프트로 넣고, Claude가 코드 실행 도구로 측정합니다.
3. 새 대화로 `--runs`회(기본 3회) 반복합니다. 논문의 "측정자 3명 × 3회"를 대신하는 방식입니다.
4. Claude가 보고한 높이를 평균한 뒤, 프로그램이 방법 1~4를 직접 계산합니다.

## 설치

```
pip install -r requirements.txt
```

Claude Console(https://platform.claude.com)에서 API 키를 발급받아 환경변수로 등록합니다.

- Windows: `setx ANTHROPIC_API_KEY "발급받은_키"` (새 터미널부터 적용)
- macOS/Linux: `export ANTHROPIC_API_KEY="발급받은_키"`

## 사용법

```
# API 호출 없이 사진 변환과 요청 내용만 확인
python run_measure.py film1.jpg film2.jpg film3.jpg --targets L2 L3 --dry-run

# 측정 (새 대화 3회)
python run_measure.py film1.jpg film2.jpg film3.jpg --targets L2 L3 --runs 3

# 저장된 결과로 표만 다시 계산
python run_measure.py --aggregate-only results/20260928_101500
```

| 옵션 | 설명 |
|---|---|
| `--targets` | 대상 골절 추체 (기본 `L2 L3`). 위·아래 인접 추체는 자동으로 함께 측정 |
| `--runs` | 독립 측정 횟수 (기본 3) |
| `--model` | 모델 ID (기본 `claude-opus-5-5`) |
| `--prompt` | 프롬프트 파일 경로 (기본 `measure_prompt.txt`) |
| `--max-tokens` | 한 번 호출의 출력 한도 (기본 32000) |
| `--keep-files` | 업로드한 사진을 실행 후 API 저장소에서 지우지 않음 |
| `--dry-run` | API 호출 없이 준비 과정만 실행 |

입력 형식: JPEG, PNG, DICOM(`pydicom` 설치 시)

## 결과

`results/<날짜_시각>/`

- `summary.csv`: 방법 1~4 압박률(개별 측정 최소~최대 포함)과 측정별 전방·후방 높이
- `run_N/`: 측정점을 그린 이미지와 Claude의 설명
- `run_N.json`: 원본 응답

## 비용 (2026년 9월 기준)

- 토큰: 100만 토큰당 Opus 5.5 입력 $4 / 출력 $20, Sonnet 5 입력 $2 / 출력 $10
- 코드 실행: 조직당 월 1,550시간 무료, 이후 컨테이너 1시간당 $0.05
- 실행 중 측정마다 토큰 요금 추정치를 출력합니다(캐시 할인 미반영, 코드 실행 시간 요금 제외).

## 개인정보

- 업로드한 사진은 실행이 끝나면 API 저장소에서 삭제합니다(`--keep-files`로 유지 가능).
- `.gitignore`가 사진 파일과 `results/` 폴더를 커밋에서 제외합니다.
